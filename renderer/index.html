关于 学霸帝 Zero-to-CAD

学霸帝 Zero-to-CAD 是一个基于 AI 视觉语言模型的 CAD 代码生成器。

如何使用

  1. 上传 3D 形状的多视图渲染图片（建议8张：4正面 + 4背面）
  2. 可选修改提示词
  3. 点击「生成 CAD」按钮
  4. AI 将自动生成可执行的 CadQuery Python 代码
  5. 复制或保存生成的代码，用 CadQuery 执行

模型信息

  • 基础模型：Qwen3-VL-2B-Instruct
  • 微调数据：Zero-to-CAD 1M（97.9万合成样本）
  • 输入：8张 256×256 渲染视图
  • 输出：可执行的 CadQuery Python 代码
  • 论文：arXiv:2604.24479

安装 CadQuery

pip install cadquery
